### About

I build the policy-lifecycle side of an insurance platform used by **7 insurers and a bank partner channel** —
domain logic, SQL and web UI, end to end — so insurers launch new products through **configuration instead of
custom code**.

I came into the product through QA: first building its automated regression suite, then leading the QA team and
owning the release gate, then moving to feature development. That path is why I treat tests and migrations as part
of the feature, not as cleanup afterwards.

Currently also finishing an **M.Sc. in Software Engineering at KPI**, where my thesis is a working product
([StoryForge](https://github.com/MrSampy/StoryForge)) rather than a paper.

**🌐 [Lexify](https://lexify-app.com/)** — *side project · live*
Vocabulary learning for any language, scheduled by a spaced-repetition algorithm so each review lands right before
you'd forget the word. Live and in daily use.

**🤖 [Pr-Reviewr](https://github.com/MrSampy/Pr-Reviewr)** — *open source*
A PR review assistant for Azure DevOps that reads the codebase and past review comments before commenting on a
diff. Retrieval-augmented, fully local — the code never leaves the machine.
`Python` `ChromaDB` `Ollama` `RAG` `Azure DevOps`

**🚁 [SAR Coordination Platform](https://github.com/MrSampy/Platform-for-coordination-of-search-and-rescue-operations)** — *open source*
Five independent .NET 8 microservices behind a React front end covering the full search-and-rescue mission
lifecycle, replacing coordination over chat and spreadsheets.
`.NET 8` `React` `PostgreSQL` `RabbitMQ` `Docker`

**📚 [StoryForge](https://github.com/MrSampy/StoryForge)** — *M.Sc. thesis product*
A hybrid `G = (N, E, C)` model for non-linear narrative graphs: automatic integrity checking (unreachable nodes,
dead ends, contradictory conditions), tree → graph deduplication, and a 75-configuration experiment harness.
`.NET 10` `React 19` `PostgreSQL` `xUnit`

## 📚 StoryForge — M.Sc. thesis

**[github.com/MrSampy/StoryForge](https://github.com/MrSampy/StoryForge)**

A system for optimising narrative-tree construction in tabletop role-playing games, built as a working
product rather than a paper. Implements a hybrid `G = (N, E, C)` model — story nodes, transitions and
constraint rules — combining tree, graph and constraint-based approaches.

- Visual story-graph editor with reusable nodes
- Conditional transitions over variables, flags and character state (JSON Condition AST)
- Automatic integrity checking: unreachable nodes, dead ends, contradictory conditions, exit-less cycles
- Structure optimisation: duplicate detection and merging (tree → graph), optimality metrics
- Playthrough simulation with world state
- Experiment harness: 75 configurations, 50–1000 nodes × duplicate ratio × 5 seeds

`.NET 10` `ASP.NET Core` `PostgreSQL 16` `EF Core` `React 19` `TypeScript` `xUnit`

## 🌐 Lexify — side project, live

**[lexify-app.com](https://lexify-app.com/)**

Vocabulary learning for any language. Every word is scheduled by a spaced-repetition algorithm so each
review lands right before you'd forget it — instead of drilling on a fixed timetable, which makes
learners over-review what they know and lose what they don't.

Live and in daily use.
